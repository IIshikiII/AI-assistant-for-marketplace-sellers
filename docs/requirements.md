# Требования к продукту

Источник: отчёт команды (Кузьмищев А., Малмыгин Г., Ким М.) «ИИ-система поддержки управленческих решений продавца на маркетплейсах» и digital-стратегия **marketPilot AI** (в `raw_docs/`, локально).

## Продукт

**marketPilot AI** — B2B SaaS для продавцов на WB, Ozon, Яндекс Маркете. Собирает данные о продажах, остатках, рекламе, отзывах, выявляет отклонения, объясняет причины и выдаёт приоритизированный список действий с экономическим эффектом. Цепочка: **данные → контекст → причина → приоритет → действие → эффект**. Критичные решения (цена, реклама, закупка) остаются за человеком.

## Пользователь

Основной ICP — средние продавцы: 100–3000 SKU, 2+ маркетплейса, регулярная реклама, команда 3–10 человек. Пользователи системы — собственник и менеджер магазина.

## Проблема

Длинный цикл управленческих решений, данные разбросаны по кабинетам и Excel, поздняя реакция на дефицит, неликвид, неэффективную рекламу и проблемы карточек.

## Целевые показатели (из отчёта)

- время принятия решения — в 2 раза меньше;
- дней out-of-stock — до нуля;
- оборачиваемость — в 2 раза лучше;
- Data Quality — 97%.

## Прототип (реализовано, 23.10.2026)

Сценарии MVP по стратегии: **остатки, реклама, карточки/отзывы** (+ цена и просадки продаж).

| Функция отчёта | В прототипе |
|---|---|
| F.03 Мониторинг KPI | Обзор: выручка, маржа после рекламы, ДРР, SKU в риске, заморожено в излишках, рейтинг |
| F.04 Отклонения и аномалии | Правила: дефицит, out-of-stock, неликвид, ДРР, волна негатива, просадки |
| F.06–F.07 Риск дефицита и пополнение | Запас в днях vs срок поставки, объём заказа |
| F.08 Цена | Просадка после повышения цены → вернуть/протестировать цену |
| F.09 Реклама | Сократить убыточные кампании, масштабировать эффективные, найти остановленные |
| F.10 Отзывы и карточка | Разбор отзывов ИИ: темы, правки карточки, претензии поставщику, шаблон ответа |
| F.12 Объяснение рекомендаций | Кнопка «Объяснить» (DeepSeek), сводка недели, ИИ-копилот по данным |
| F.13 Фиксация решения | Принять/отклонить с комментарием → журнал решений |

Данные — детерминированный демо-магазин (22 SKU, WB + Ozon, 60 дней), см. `services/demo_data.py`.

## Не входит в прототип

Коннекторы API маркетплейсов (F.01), загрузка XLSX, ML-прогноз спроса (F.05, сейчас — среднее за 14 дней), сценарное моделирование (F.11), уведомления (F.14), роли и мультиаккаунт.
